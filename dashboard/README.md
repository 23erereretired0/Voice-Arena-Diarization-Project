# Voice Arena dashboard (simplified)

One static page (`index.html`) plus `aggregate.js` (ranking maths) and `data/benchmark_results.js` (generated by `mini_eval/scripts/export_dashboard.py`). There is no build step and no framework.

## Open it

- **View results only:** open `dashboard/index.html` in a browser. Keep the folder intact.
- **With audio upload:** from the project root run `python server/app.py`, then open http://127.0.0.1:8765/. Opened as a file, the page can preview audio but cannot run a model.

## What is on the page

| Part | What it does |
|---|---|
| Header | Name, recording count, measured/not-run status, last evaluation date, **Customize Ranking** and **Upload Audio** |
| Overall leaderboard | Systems ranked by pooled DER, with CI, macro and median DER, JER, components, overlap and non-overlap DER, speaker-count MAE, boundary median/p95, runtime, RTF, cost, failures and recordings scored. A **Details** row shows model version, packages, hardware, scoring settings and configuration |
| Metric tooltips | Hover, keyboard focus or tap a heading: full name, definition, formula, units, direction and limitation |
| Customize Ranking | Five filters (recording type, speakers, overlap, audio quality, microphone). Systems are reranked from the matching recordings only; fewer than 3 scored matches shows "Insufficient evidence". The overall table is never changed |
| Recordings | All benchmark recordings with documented conditions. "What happened in this recording?" shows per-system metrics, generated summaries (labelled measured or hypothesis) and reference/prediction timelines |
| Evaluate your own audio | Upload, preview, run pyannote on the local server, timestamped segments, timeline, RTTM/JSON download, optional reference RTTM scoring. Personal uploads never enter the benchmark |

**Data rules:**
- All numbers come from `data/benchmark_results.js`, which holds real pipeline output only. Currently: the measured 5-recording run (pyannote vs Deepgram); NeMo shows "Not run". In the not-run state, the table shows dashes.
- Conditions without documented evidence are "unknown" and match only "All".
- The earlier multi-tab dashboard and its fictional "Example System" data were removed so demo values can never mix with measured ones.

## Tests

- `node dashboard/tests/aggregate.test.js`: ranking and aggregation maths on synthetic inputs (11 tests).
- `python dashboard/tests/browser_check.py`: 69 Playwright checks with measured data (75 in the not-run state).
  - Covers the shipped data at 1366 and 390 px, plus a synthetic measured dataset in a temporary copy (never written to the project).
  - Covers the upload flow against the real local backend, with a mocked success response for the result view.
  - Optional dev dependency: `pip install playwright && playwright install chromium`.
